# LP Flutuantes RVA Agro | Vazão Engenharia

Landing page estática (HTML/CSS/JS puro) da linha de flutuantes RVA Agro distribuída pela Vazão Engenharia.

- `index.html`: página única, com um carrossel de modelos por linha de produto (6 linhas, 45 modelos do catálogo).
- `assets/img/modelos/`: foto de cada modelo, extraída do catálogo.
- `assets/catalogo-flutuantes-rva-agro.pdf`: catálogo para download.

Sem build: publique a pasta como site estático (Vercel, Netlify etc.).
